# gizem-akdag-study

`gizem-akdag-study` 是一个非官方、学习型 Codex Skill，用于研究并实践一种克制的超现实摄影转化方法。它从真实照片的结构出发，通过观察、提纯和关系错位建立“像被相机真实记录下来”的诗意荒诞。

> **版本：v1.0**  
> 本项目与 Gizem Akdag 本人无隶属、授权或背书关系，也不声称生成内容是其作品。名称中的 `study` 明确表示视觉研究与学习用途。

## 核心方法

**现实 → 观察 → 提纯 → 关系错位 → 诗意荒诞 → 新现实**

本 Skill 不把风格理解成滤镜。它要求先读取原始照片，寻找环境秩序、重复、纹理、大色块与现实锚点，再决定删除什么、提纯什么，以及是否需要一个源自原图关系的超现实错位。

它特别强调：

- 让自然或环境成为大面积视觉母体。
- 将人物、动物或建筑提纯为孤立而可辨认的视觉符号。
- 通过尺度、位置、功能、色彩或空间关系错位产生诗意荒诞。
- 让颜色承担构图、重量、节奏、距离和空间分层。
- 用统一的光影、透视、材质、接触和镜头逻辑保持摄影真实性。
- 避免无意义换背景、巨月与雾等奇幻套件、单纯美化和过度电影化。

## 安装

### 下载后安装

1. 下载并解压本仓库。
2. 将完整的 `gizem-akdag-study` 文件夹复制到 Codex Skills 目录：

```text
~/.codex/skills/gizem-akdag-study
```

3. 重新启动或刷新 Codex，使其重新发现 Skills。

### 从 GitHub 安装

仓库发布到 GitHub 后，也可以使用 Codex 的 Skill 安装功能，从仓库地址安装。仓库根目录必须保留 `SKILL.md`，且文件夹名保持为 `gizem-akdag-study`。

## 使用示例

```text
使用 $gizem-akdag-study 分析这张真实照片。
先解释环境秩序、现实锚点和视觉噪音，
再提出一个克制的关系错位方案，并给出编辑提示词。
```

```text
使用 $gizem-akdag-study 诊断这张生成结果为什么太像泛 AI 奇幻，
并在不更换真实场景的前提下给出下一轮修改方案。
```

```text
使用 $gizem-akdag-study 比较原图和当前版本，
只调整色彩的空间职责，不改变主错位。
```

## 默认输出

Skill 默认依次给出：

1. 现实读取
2. 视觉秩序
3. 转化命题
4. 保留 / 删除 / 提纯
5. 主错位
6. 色彩结构
7. 摄影真实性约束
8. 编辑说明、生成提示词或批评意见

如果用户要求直接编辑或生成图像，Skill 仍会先完成视觉判断，再调用可用的图像工具。

## 如何继续迭代

新增研究样本时，不要直接把单张作品的特点提升为普遍规律。建议把观察分成三类：

- **重复规律**：在多个样本中反复出现，可作为方法候选。
- **局部特征**：只适用于某张作品或某类场景。
- **待验证推测**：目前证据不足，不写成摄影师意图或事实。

每次更新应说明修改的是构图、色彩、错位、摄影真实性还是失败诊断，并用真实任务重新检查 `SKILL.md` 的决策清单。

## 使用边界

本仓库只提供研究方法与工作流程，不包含或授权任何摄影作品。使用者应确保自己有权处理输入照片，并在公开发布输出时避免造成官方合作、授权或作者身份的误解。
