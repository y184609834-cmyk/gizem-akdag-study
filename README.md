# gizem-akdag-study v2.0

A study-driven visual workflow for transforming real photographs into restrained, poetic surreal editorial images.

## Core chain

**Reality → Observe → Purify → Recompose relationships → Poetic absurdity → New reality**

## v2.0 emphasis

The biggest update is a move away from formulaic surreal tricks.

This version:
- removes the “single impossibility” requirement
- removes giant-object defaults
- removes portal/white-door defaults
- removes mandatory high saturation
- removes fixed palettes
- removes mandatory minimalism
- adds a 3-proposition concept stage before generation
- prioritizes relationship redesign over object insertion
- adds form-rhyme and subject/environment fusion
- treats color as structure rather than a saturation slider
- adds a two-look test and scoring rubric
