# Landscape and Architecture

## Goal

Turn the environment into a designed visual system without losing the source location's memory.

## Read the scene as abstract structure

Translate:
- forest → texture field
- lake → surface plane
- road → line
- mountain → mass
- village → color cluster
- bridge → rhythm
- shoreline → graphic boundary

## Strong transformations

### Spatial hierarchy shift
Make an existing feature unexpectedly dominant or subordinate.

### Material reinterpretation
A mountain may behave like fabric, foam, pigment, or architecture while still retaining geological credibility.

### Repetition
A source element can multiply to create a new rule of the world.

### Isolation
A building/animal/person can become a visual island when the environment is purified around it.

### Functional displacement
A road can behave like water.
A shoreline can behave like a ribbon.
A building can behave like a landform.

## Avoid

- default white portal
- default giant moon
- generic surreal monument
- total background replacement
- turning every landscape into the same minimal scene
